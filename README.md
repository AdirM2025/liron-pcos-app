# המסע של לירון — הפעלה עצמאית מהטלפון

זו החבילה שהופכת את האפליקציה מ"קובץ שנפתח רק במחשב שלך" לאתר אמיתי שלירון פותחת ישירות מהטלפון, עם צ'אטבוט AI אמיתי מאחורי הקלעים — **לגמרי בחינם**, כולל הצ'אטבוט (מבוסס Gemini, לא דורש כרטיס אשראי).

יש שני חלקים: **`index.html`** (האפליקציה עצמה — עולה ל-GitHub Pages, חינם) ו-**`worker/`** (שרת קטן שמחזיק את מפתח ה-API בבטחה ומדבר עם Gemini — עולה ל-Cloudflare Workers, גם חינם).

התיקייה כבר מוכנה כ-git repo עם קומיט ראשון. אתם רק צריכים לחבר אותה לריפו שלכם ולדחוף.

---

## שלב 1 — להוציא מפתח API של Gemini (חינמי, בלי כרטיס אשראי)

1. גשו ל-**aistudio.google.com/apikey** והתחברו עם חשבון גוגל.
2. לחצו **Create API key** ושמרו אותו במקום בטוח (לא בקובץ, לא בצ'אט — רק בשלב 3 למטה).
3. זהו. אין תשלום, אין כרטיס אשראי. יש מכסה יומית חינמית (מאות עד אלף+ בקשות ביום) — הרבה מעבר למה שצ'אטבוט אישי כזה צריך.

## שלב 2 — להעלות את index.html ל-GitHub Pages

```bash
cd liron-pcos-deploy
git remote add origin https://github.com/<שם-המשתמש-שלך>/liron-pcos-app.git
git branch -M main
git push -u origin main
```

(אם אין לכם עדיין את הריפו — צרו אותו קודם ב-GitHub כ-**public** repo בשם `liron-pcos-app`, בלי README, ואז הריצו את הפקודות למעלה.)

לאחר הדחיפה: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
אחרי דקה-שתיים האתר יהיה זמין ב: `https://<שם-המשתמש-שלך>.github.io/liron-pcos-app/`

## שלב 3 — לפרוס את ה-Worker (המוח של הצ'אטבוט)

```bash
cd worker
npm install -g wrangler   # אם עדיין אין
wrangler login             # ייפתח דפדפן להתחברות לחשבון Cloudflare (חינמי)
wrangler deploy
wrangler secret put GEMINI_API_KEY
# ← כאן מדביקים את המפתח מ-aistudio.google.com/apikey (הקלדה מוסתרת, לא נשמר בקבצים)
```

בסיום `wrangler deploy` תקבלו כתובת כמו:
`https://liron-pcos-bot.<שם-המשתמש>.workers.dev`

## שלב 4 — לחבר בין השניים

פתחו את `index.html`, חפשו את השורה:

```js
const WORKER_URL = "https://REPLACE_WITH_YOUR_WORKER_URL.workers.dev";
```

והחליפו בכתובת האמיתית מהשלב הקודם. שמרו, ואז:

```bash
git add index.html
git commit -m "חיבור לצ'אטבוט"
git push
```

תוך דקה השינוי יופיע גם ב-GitHub Pages. זהו — לירון פותחת את הקישור מהטלפון, ומקבלת את כל האפליקציה כולל צ'אטבוט חכם, בלי שום עלות.

**טיפ:** בספארי/כרום בטלפון, "שיתוף → הוספה למסך הבית" הופך את הקישור לאייקון שנראה ומרגיש כמו אפליקציה אמיתית.

## למה Gemini ולא Claude כאן?

ב-Cowork (בדסקטופ) הצ'אטבוט מדבר עם קלוד ישירות דרך הגשר המובנה של Cowork — זה כבר כלול ולא עולה כלום נוסף. אבל כדי שהאפליקציה תעבוד **עצמאית** (מחוץ ל-Cowork, כאתר משלה), היא צריכה להתחבר ישירות ל-API של מודל שפה — ול-Claude API אין מסלול חינמי אמיתי, רק קרדיט בתשלום. ל-Gemini יש שכבה חינמית אמיתית שמספיקה בנוחות לשימוש אישי כזה, אז זה הבחירה המעשית כאן. מבחינת האיכות עבור המשימה הזו (שיחות תמיכה קצרות, לא קידוד מורכב) ההבדל לא יורגש.

חשוב לדעת: Cowork עצמו זמין היום גם מהנייד (iOS/Android), אבל לפי התיעוד הרשמי של Anthropic, **live artifacts** (בדיוק כמו האפליקציה הזו) עדיין זמינים רק בדסקטופ ולא מופיעים בתצוגת הארטיפקטים בנייד — לכן המסלול הזה של GitHub Pages הוא הדרך האמיתית לגרום לזה לעבוד מהטלפון שלה.

## מה עובד איפה

| תכונה | ב-Cowork (מחשב) | ב-GitHub Pages (טלפון) |
|---|---|---|
| יומן אוכל, קלוריות, מים, אימונים, גרפים | ✅ | ✅ (הכל נשמר מקומית בדפדפן של המכשיר) |
| צ'אטבוט וצ'ק-אין שבועי חכם | ✅ ישירות (קלוד) | ✅ דרך ה-Worker (Gemini), אחרי שלבים 1-4 |

שימו לב: הנתונים (יומן האוכל, ההיסטוריה) נשמרים בדפדפן של **המכשיר שבו פותחים את הקישור**. אם לירון פותחת גם מהטלפון וגם מהמחשב, אלה שני מקומות אחסון נפרדים — לא מסונכרן ביניהם. לשימוש יומיומי, הכי פשוט שתשתמש תמיד מאותו מכשיר (הטלפון).

## אבטחה — מה כדאי לדעת

מפתח ה-API עצמו **לא** חשוף בשום מקום בקוד הציבורי — הוא יושב רק בתוך Cloudflare כ"secret". כתובת ה-Worker כן גלויה בקוד הפתוח (זה בלתי נמנע באתר סטטי), כך שתיאורטית מישהו שימצא את הכתובת יוכל לשלוח אליה בקשות. מכיוון שמדובר בשכבה חינמית, אין כאן חשיפה כספית — הגרוע ביותר שיכול לקרות הוא שהמכסה היומית תיגמר מוקדם, לא חיוב בכרטיס אשראי.
